# 🥛 Milk Adulteration Detection Using Machine Learning

## 📌 Project Overview

This project predicts whether a milk sample is **Pure** or **Adulterated** using Machine Learning based on laboratory test parameters.

## 📊 Dataset

- Total Samples: 2500
- Selected Features: 18
- Target Variable: Is_Adulterated

## 🤖 Machine Learning Model

- Decision Tree Classifier

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-Learn
- Plotly
- Joblib
